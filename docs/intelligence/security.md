# Intelligence security boundary

The first slice rejects unsafe schemes, embedded URL credentials, localhost, loopback, private, link-local, reserved, unspecified, cloud metadata, and non-standard URL ports. It bounds evidence excerpts and never returns credentials, tokens, database URLs, filesystem paths, stack traces, or raw provider payloads.

External research is disabled by configuration. No outbound call is made by System Doctor or the local foundation run. Future document parsing must add quarantine, malware scanning, HTML sanitization, prompt-injection handling, DNS rebinding defenses, robots/terms checks, and provider rate limits before enablement.
