# WordPress test-site validation

Use only an operator-controlled non-production WordPress site and an application password with
minimum post/media permissions. Validate connection, taxonomy discovery, media upload, draft,
update, reconciliation, and move-to-draft. Record only operation, outcome, test post ID, safe URL,
latency, and correlation ID.

The application has no remote-delete operation. If permitted, clean up test posts and media
manually in WordPress.
