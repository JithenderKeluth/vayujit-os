# VAYUJIT OS 0.1.0-rc.1

## Scope

The first Windows local-MVP release packages the secure Electron shell and Angular renderer and
documents the supported local FastAPI/PostgreSQL runtime.

## Included capabilities

Owner authentication, brands, products, deterministic AI content, approvals, mock/WordPress/
Shopify publishing flows, campaigns, durable scheduling and workers, Recovery, rescheduling,
catch-up, Operations, backups, maintenance mode, accessibility lint, and the local performance
baseline.

## Supported platform and prerequisites

Windows 10/11 x64, PostgreSQL 17, and Python 3.12. PostgreSQL and Python are prerequisites and
are not bundled. Redis is not required.

## Installation and first run

Download `VAYUJIT-OS-0.1.0-rc.1-Setup.exe` and its `.sha256` file, verify the checksum, install as
the current user, install the packaged API runtime, start the API launcher, then launch VAYUJIT
OS. First launch presents owner setup; subsequent launches present login.

## Upgrade and backup

Close the application and run the newer per-user installer. The packaged API launcher creates and checksums a custom-format `pg_dump` backup under `%LOCALAPPDATA%\VAYUJIT OS\backups` before `alembic upgrade head`; any backup failure stops startup and leaves the database untouched.

## Security and data

Electron retains sandboxing, context isolation, disabled Node integration, web security, app-scheme
navigation, and denied permission requests. Connector credentials remain encrypted and are never
packaged. User data lives under `%LOCALAPPDATA%\VAYUJIT OS`; uninstall preserves it by default.

## Connector status and limitations

Mock connector acceptance is deterministic. WordPress and Shopify tests use controlled fakes; real
remote services are not contacted by the release validation. Automatic updates, cloud hosting,
Redis, multi-user authorization, and remote deletion are not included. Visual screen-reader and
contrast review remains a release-environment follow-up.
